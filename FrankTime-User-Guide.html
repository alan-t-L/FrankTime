FrankTime / FrankZeit User Guide

FrankTime / FrankZeit is a bilingual Android app that displays and converts time using the Frank Time system. It supports English and German and can be switched between the two languages from its main screen.

Getting started

  1. Install FrankTime / FrankZeit on your Android device.
  2. Open the app.
  3. The main screen shows the Frank Time clock and conversion controls.
  4. Use the language button to change between English and German.

Main screen

The main screen contains the following elements:

  • Title: FrankTime in English or FrankZeit in German.
  • Subtitle: a short description of the app in the selected language.
  • Clock: displays the current time in Frank Time format.
  • Language button: switches between English and German.
  • Conversion buttons: convert between conventional time and Frank Time.
  • Result displays: show the converted result.
  • Footer: displays the app version and copyright.

Using the conversion buttons

Use the conversion buttons to convert a time between conventional clock time and Frank Time.

  1. Enter or select the time you wish to convert, following the controls shown on the main screen.
  2. Tap the appropriate conversion button.
  3. Read the result in the result area.

In German mode, minute-related conversion labels use Minuten.

Installing an APK manually

If you have copied an APK file to your phone, follow these steps:

  1. Open the Files or My Files app.
  2. Go to Internal Storage.
  3. Open the FrankTimeApp folder.
  4. Open either Debug Version or Signed Release Version.
  5. Tap the APK file.
  6. If Android asks whether to allow installation from this source, choose Allow.
  7. Tap Install.
  8. When installation finishes, tap Open or find FrankTime / FrankZeit in your app list.
Note: A debug APK may trigger Android’s installation-from-unknown-sources warning. This is normal for apps installed outside the Google Play Store. Only install APK files that you created or received from a trusted source.

Building the app

The app can be built from the project folder using PowerShell.

Build a debug version

.\Build-FrankTime.ps1 -BuildType Debug

Build an unsigned release version

.\Build-FrankTime.ps1 -BuildType Release

Build a signed release version

.\Build-FrankTime.ps1 -BuildType Signed-Release `
    -KeystorePath "C:\Path\To\franktime-release.keystore" `
    -KeyAlias "franktime" `
    -KeystorePassword "YourKeystorePassword" `
    -KeyPassword "YourKeyPassword"

Build and install directly

.\Build-Install-FrankTime.ps1 -BuildType Debug

Build and copy to the phone

.\Build-Copy-FrankTime.ps1 -BuildType Debug

For a signed release copy, use -BuildType Signed-Release and provide the keystore details.

Troubleshooting

The app will not install

  • Check that the APK is a signed release APK if you are installing a release version.
  • Allow installation from the Files app if Android requests permission.
  • Ensure there is enough free storage space on the device.
  • If an older version is installed, try uninstalling it first if Android reports a signature conflict.

The device is not detected

  • Connect the phone using a data-capable USB cable.
  • Enable USB debugging in Developer options.
  • Accept the USB debugging authorization prompt on the phone.
  • Run adb devices to confirm that the device appears.

Release APK will not install

A normal release build may create an unsigned APK. Android cannot install an unsigned release APK. Build a signed release version instead using the Signed-Release option and your release keystore.
